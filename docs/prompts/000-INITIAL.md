Create a prompt which will use the /ce:brainstorm command to create a brainstorm document for the following system:

## Scope

This system will be a "planner" - a tool for human beings to journal their routine (document the past) and plan ahead their next day or week (document the future).

The distinctive feature of this particular application is that it will start simple then adapt to the user profile. Meaning this application should be able to become one of multiple ways a planner can be.

## Research

We need to structure several approaches to personal planning and be able to implement each one of them, in order to make a personalized planner for several different kind of people.

## Tech stack

This will be a web application written in Python using FastAPI and Flask (or Quart).

The FastAPI application should be able to handle a mobile application which will be written in the future.

The Flask application should use FastAPI as a backend.
